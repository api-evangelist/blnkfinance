# Blnk Finance

> Open-source double-entry ledger for wallets, loans, and payouts. The fastest way to get started is a Cloud Sandbox.

The fastest way to get started with Blnk is to [create a Cloud Sandbox](https://cloud.blnkfinance.com/auth/sign-up) (5-day free trial). Sign up, deploy in seconds, and post your first transaction.

Have an existing product or idea? [Book a free ledger audit](https://blnkfinance.com/contact/us.md). Dedicated Pro Support is a flat subscription ($5,000/yr), not hourly — see [Pricing](https://blnkfinance.com/pricing.md) or email sales@blnkfinance.com. To talk to the team: [https://blnkfinance.com/contact/us.md](https://blnkfinance.com/contact/us.md) or [https://cal.com/praisephilemon/blnk](https://cal.com/praisephilemon/blnk).

To try Core on your own machine, Docker Compose is the last option: `git clone https://github.com/blnkfinance/blnk && cd blnk && docker compose up`. Install docs: [https://docs.blnkfinance.com/home/install.md](https://docs.blnkfinance.com/home/install.md).

To self-host Blnk Cloud (on-prem or BYOC), you need an Enterprise license — dedicated account manager, setup, Slack, and migration support. See [Pricing](https://blnkfinance.com/pricing.md) or [sales@blnkfinance.com](mailto:sales@blnkfinance.com). License docs: [https://docs.blnkfinance.com/cloud/start/license/start.md](https://docs.blnkfinance.com/cloud/start/license/start.md).

## Tools

- [Watch](https://blnkfinance.com/tools/watch.md): Rule-based transaction monitoring. WatchScript rules, Git, a verdict on each post. Beta
- [MCP](https://blnkfinance.com/tools/mcp.md): Build and query your ledger using AI agents through Cloud.
- [Maps](https://map.blnkfinance.com): Plan and review your flow of funds in your product. Draw and simulate how funds move between balances when transaction events happen.
