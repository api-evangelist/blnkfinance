# Blnk Finance

Open-source double-entry ledger for financial products (wallets, loans, payouts, escrow, cards). Available as self-hosted Blnk Core (OSS engine) and Blnk Cloud (managed), plus Blnk Watch for transaction monitoring. Exposes REST APIs with a public OpenAPI spec, hosted MCP servers, llms.txt, and installable agent skills.

## APIs

- **Blnk Core API** — Primary open-source ledger REST API (ledgers, balances, transactions, inflight, refunds, balance monitors, identities, accounts, backup). Self-hosted; default server is localhost:5001 with no fixed public host. Auth via X-Blnk-Key header. (`http://localhost:5001`)
- **Blnk Cloud API** — Managed Cloud REST surface covering OAuth auth, a Proxy API to a Core instance, Data API, Filters API, Alerts API, and the MCP endpoint. Auth via API keys or OAuth. (`https://api.cloud.blnkfinance.com`)
- **Blnk Watch API** — Rule-based transaction monitoring API (transaction evaluation, instruction management, Git-backed rule sync). Beta. (`https://api.cloud.blnkfinance.com`)

> Public OpenAPI 3.0 spec confirmed at https://docs.blnkfinance.com/openapi.json. Two hosted MCP servers exist: the open no-auth documentation MCP at https://docs.blnkfinance.com/mcp, and a Cloud-proxied ledger MCP at https://api.cloud.blnkfinance.com/mcp/{instance_id} (requires Blnk Cloud Sandbox/Production tiers and Bearer auth with mcp:read/mcp:write scopes) — the latter uses a per-instance template URL and is not cataloged as a static MCPServer property but is documented at https://docs.blnkfinance.com/cloud/reference/mcp.md. Agent skills are installable via 'npx skills add https://docs.blnkfinance.com' (/blnk entry point). llms.txt is live at both blnkfinance.com and docs.blnkfinance.com. The Core REST API has no fixed public base URL (default localhost:5001); the hosted surface is api.cloud.blnkfinance.com. No public AsyncAPI, GraphQL, or Postman collection found.
